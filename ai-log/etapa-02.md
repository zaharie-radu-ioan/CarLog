## What I learned / what did not work

Immutable functions return a new array instead of changing the one they receive: `map`, `filter` and `reduce` build new lists, and `[...list, item]` and `{ ...item, done: !item.done }` replace `push` and direct assignment. The new id is the highest existing id plus one, because `length + 1` creates duplicates after a delete. `sort()` changes the array it is called on, so it is called on a copy. The file name and line next to each console message show where it comes from.
What did not work at first: the WebSocket error looked like a bug in my code, but it comes from Live Server and has nothing to do with `carlog.js`.
